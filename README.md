# PACMAN

Java implementation of the classic Pac-Man game with a Swing graphical interface.

## How to run

1. Compile P1 and P2:
```
javac -d out -cp src src/P1.java
javac -d out -cp src src/P2.java
```
2. Run P1 and P2:
```
java -cp out P1
java -cp out P2
```
> P1 must be run before P2.

## CSV files

**jogador.csv**
```
nome,vidas
Jogador,3
```

**fantasmas.csv**
```
nome,tipo,cor
Blinky,blinky,FF0000
Pinky,pinky,FFB8FF
Inky,inky,00FFFF
Clyde,clyde,FFB852
```

**mapas/mapaX.csv** — grid of integers where:
- `0` = empty
- `1` = wall
- `2` = dot (+10 pts)
- `3` = power-up (+50 pts)
- `4` = Pac-Man starting position
- `5` = ghost base
